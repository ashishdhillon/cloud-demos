ℹ️ Cloud Provider Subnet IP Reservation (RFC 1918)

Every AWS/Cloud /24 subnet allocates 256 addresses, but 5 are reserved and cannot be assigned to hosts:

  • .0 → Network Address (Subnet identifier)
  • .1 → VPC Default Router Gateway
  • .2 → Amazon DNS Resolver (Base + 2)
  • .3 → Future AWS Cloud Reservation
  • .255 → Network Broadcast Address
