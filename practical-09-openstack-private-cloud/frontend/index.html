🎓 Student Lab Guide: How to Perform this Practical

Step-by-Step Hands-on Walkthrough
1
Task 1: Multi-Tenant Switching

In the top bar, switch between "Production-Core" and "Dev-Staging". Notice how OpenStack isolates compute instances, private subnets, and quota limits!

2
Task 2: Launch Compute Instance

Click "➕ Launch Cloud Instance". Choose a Flavor (e.g. m1.small), a Glance Image (Ubuntu 24.04), check "Assign Floating IP", and launch!

3
Task 3: Neutron Floating IP Binding

On any active instance, click "🌐 Toggle Floating IP" to see how OpenStack Neutron SDN binds public internet IPs to private tenant subnets.

4
Task 4: OpenStack CLI Console

In the right panel, click "openstack token issue" and "openstack server list" to test standard OpenStack REST CLI calls.
