⚙️ Linux Cgroups & Resource Throttling

Kernel Quota Inspector

Linux Control Groups (cgroups) meter, throttle, and isolate memory, CPU cycles, and process IDs (PIDs) assigned to container runtimes.

Memory Limits (memory.max & memory.current)

32 MB / 128 MB
Enforced container hard limit: 128 MB. If memory crosses 100%, the Linux kernel initiates an immediate OOM-Killer termination (SIGKILL).

Completely Fair Scheduler (CFS) CPU Throttling

Quota: 0.50 Cores
Controlled via /sys/fs/cgroup/cpu.max (50,000us per 100,000us period). When high-compute tasks consume all allocated CFS quota, the kernel pauses the thread.

🧱 Docker Image Layers & UnionFS (OverlayFS)

Copy-on-Write (CoW)

Docker images are stacked immutable read-only filesystem layers. When a container runs, Docker attaches a thin ephemeral Read-Write layer on top using OverlayFS.
