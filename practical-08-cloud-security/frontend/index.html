🔐 KMS Envelope Encryption & Decryption Lab

DEK & KEK Pattern

Cloud applications never send large files directly to KMS. Instead, they use Envelope Encryption: KMS generates a fast symmetric Data Key (DEK), the app encrypts the payload locally, and wipes the plaintext key from memory.
