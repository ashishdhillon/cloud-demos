Task 1: Inspect Provisioned VM

Look at the virtual machine fleet on the left. Observe cloud-vm-node-01 running Ubuntu 24.04 with 2 vCPUs, 2048 MB RAM, and an assigned IP (192.168.122.45).

2
Task 2: In-Guest Serial Shell

In the right panel, use the Guest Serial Console quick buttons. Run lscpu, free -m, and curl http://localhost to verify Nginx provisioned by cloud-init!

3
Task 3: ACPI Lifecycle Transitions

Click "⏸ Suspend" to freeze CPU state to RAM, then "⏯ Resume". Click "⏹ Stop" for ACPI graceful shutdown, then "▶ Start" to power back up.

4
Task 4: Snapshots & Hardware Resize

Click "📸 Snapshot" to capture point-in-time state. Stop the VM and click "⚙ Resize" to scale up to 4 vCPUs / 4096 MB RAM, proving elastic IaaS scalability!
